# 第 2 章：遊戲世界與規則

## 本章學習目標

- 掌握三勢力、九城與四十二位武將的初始版圖結構，理解節點鄰接關係如何定義戰略空間。
- 精確計算金錢與糧食收入公式，並理解隨機擾動區間與部隊維持成本對經濟循環的影響。
- 解析內政開發公式中武將政治力乘數的作用，評估不同能力武將對城池發展效率的差異。
- 理解軍事調度中的兵力門檻、戰鬥損耗計算邏輯與城防防守結算機制。
- 明確對局結束時的勝負判定準則，即依城池數與總兵力之字典序裁定。

## 2.1 版圖與初始狀態

本遊戲引擎採用確定性的初始狀態構建，定義了三個勢力、九座城池與四十二位武將的對峙格局。這三個勢力分別為 faction_1（曹操）、faction_2（劉備）與 faction_3（孫權）。每個勢力各擁有三座城池，形成對稱的初始版圖。faction_1 擁有許昌、陳留與襄陽；faction_2 擁有洛陽、宛城與漢中；faction_3 擁有建業、吳郡與會稽。這種配置確保了遊戲開始時各勢力在資源與領土上具有基本的平衡性，同時透過城池的地理位置與鄰接關係引入戰略深層。

九座城池的分布構成了遊戲的核心地圖拓撲。根據 initial_state.py 中的定義，城池之間的鄰接關係（adjacency）是雙向的，決定了武將移動與攻城的可行性。具體而言，陳留僅與許昌相連；許昌與陳留、洛陽及襄陽相連；洛陽與許昌、襄陽及宛城相連；襄陽與洛陽、許昌及建業相連；建業與襄陽及吳郡相連；宛城與洛陽及漢中相連；漢中僅與宛城相連；吳郡與建業及會稽相連；會稽僅與吳郡相連。這種線性與分支混合的結構，使得襄陽成為連接北方與南方的關鍵樞紐，而許昌與洛陽則構成北方的核心防禦帶。

## 2.2 經濟與維持循環

遊戲的經濟系統建立在每回合開始時的金錢與糧食收入計算之上。根據 game.py 中的 apply_income 函式，每座城池的金錢收入由商業值（commerce）決定，公式為 commerce // GOLD_INCOME_DIV，其中 GOLD_INCOME_DIV 定義為 3。糧食收入則由農業值（agriculture）決定，公式為 agriculture // 4。這兩個基礎收入值並非固定不變，而是會受到隨機擾動的影響。具體來說，金錢收入會乘以一個在 U(0.8, 1.2) 區間內均勻分佈的隨機數 rg，糧食收入則乘以另一個在 U(0.8, 1.2) 區間內均勻分佈的隨機數 rf。這種設計引入了隨機性，使得經濟發展具有一定的不確定性，增加了遊戲的策略深度。

除了收入之外，部隊的維持成本是經濟循環中的關鍵支出項。每回合，每座城池的駐軍會消耗糧食，消耗量為 troops // 10。這意味著兵力越多的城池，其糧食壓力越大。如果城池的糧食在扣除維持成本後低於零，則觸發斷糧機制：糧食值被強制設為 0，同時駐軍發生逃兵，兵力減少 10%（即 troops = troops * 9 // 10）。這一機制強調了糧食供應的重要性，迫使玩家在擴張兵力與維持糧食儲備之間取得平衡。若長期忽視糧食生產，將導致兵力自然衰減，進而影響軍事行動的能力。

經濟循環的穩定性直接影響勢力的長期發展。高商業值能帶來穩定的金錢收入，用於開發內政或徵兵；高農業值則能支撐大規模駐軍，減少斷糧風險。玩家需根據城池的初始數值與發展潛力，制定相應的經濟策略。例如，初始商業值較高的城池適合優先發展商業以獲取現金流，而農業值較高的城池則適合優先發展農業以保障糧食安全。這種動態平衡是遊戲策略的核心之一，要求玩家具備長遠的規劃能力與對隨機性的應對策略。

## 2.3 內政開發與武將能力

內政開發是提升城池生產力與防禦力的主要手段。遊戲提供三種開發類型：農業（develop_agri）、商業（develop_commerce）與防禦（develop_defense）。每次開發行動需支付固定的金錢成本 DEVELOP_COST，定義為 50。開發的增量並非固定值，而是取決於執行開發的武將的政治力（politics）。開發增益公式為 base * (50 + politics) // 100，其中 base 為對應開發類型的基礎增量。具體而言，農業開發的基礎增量 DEVELOP_AGRICULTURE_BASE 為 50，商業開發的基礎增量 DEVELOP_COMMERCE_BASE 為 50，防禦開發的基礎增量 DEVELOP_DEFENSE_BASE 為 25。

武將的政治力直接影響開發效率。政治力越高，開發增益越大。例如，若武將政治力為 50，則農業開發增益為 50 * (50 + 50) // 100 = 50；若政治力為 90，則增益為 50 * (50 + 90) // 100 = 70。這種線性增長關係鼓勵玩家將高政治力的武將分配至內政任務，以最大化資源產出。反之，低政治力的武將適合從事軍事行動，以發揮其武力（war）與統御（leadership）的優勢。這種能力專化設計增加了人員調度的策略性，要求玩家根據武將的綜合屬性進行合理配置。

開發行動的執行還受到金錢成本的約束。由於每次開發需支付 50 金錢，玩家在進行開發前必須確保城池擁有足夠的金錢儲備。若金錢不足，開發行動將無法執行，這可能導致開發中斷或延遲。因此，玩家需在金錢收入與開發支出之間進行精確計算，以確保開發計劃的順利執行。此外，開發增益的整數除法特性意味著低政治力武將的開發效率可能較低，進一步強化了高政治力武將的價值。

## 2.4 軍事調度與攻城門檻

軍事行動的核心是攻城（siege），其執行受到嚴格的最小兵力限制。根據 schema.py 中的定義，MIN_SIEGE_TROOPS 設為 500，這意味著任何攻城行動必須動用至少 500 的兵力。此外，出征兵力必須以 100 為級距（SIEGE_TROOP_STEP），且出發城池必須保留至少 100 的留守兵力（SIEGE_MIN_GARRISON）。這些限制確保了軍事行動的合理性，防止玩家以極小兵力進行無效的攻城嘗試，同時保障了出發城池的基本防禦能力。

攻城戰的結算基於攻防雙方的實力對比。攻擊方實力 atk_base 計算為 c * (0.5 + (officer.war + officer.leadership) / 200)，其中 c 為出征兵力，officer.war 與 officer.leadership 為出征武將的武力與統御值。防守方實力 dfn_base 計算為 def_troops * (1 + defender_city.defense / 200) * (0.5 + dq / 100)，其中 def_troops 為防守城池的駐軍，defender_city.defense 為城防值，dq 為城內最優守將的 (war + leadership) / 2，若無存活守將則取 NO_OFFICER_DEFENSE_SKILL = 40。此公式綜合考量了兵力、武將能力與城防設施，反映了真實戰爭中的多維因素。

戰鬥結果由隨機擾動後的實力對比決定。攻擊方與防守方實力各乘以 U(0.85, 1.15) 區間的隨機數。若攻擊方實力大於防守方，則攻城成功，防守城池易主，攻擊方存活兵力進駐該城；若攻擊方實力小於或等於防守方，則攻城失敗，攻擊方遭受較大損失並返回出發城池。攻城失敗時，攻擊方損失為 int(c * min(0.8, max(0.3, 0.5 * dfn / atk)))，防守方損失為 int(def_troops * min(0.3, 0.15 * atk / dfn))。這一損耗機制鼓勵玩家在攻城前進行充分的實力評估，避免無謂的兵力消耗。

## 2.5 勝負判定準則

對局的結束與勝負判定基於城池數與總兵力的字典序比較。當遊戲進行至指定回合數或僅剩一個勢力擁有城池時，遊戲結束。勝負判定函式 compute_winner 計算每個勢力的得分，得分為 (城池數, 總兵力) 的元組。系統選取得分最高的勢力為勝者；若多個勢力的得分完全相同，則判定為平局，返回 None。這種判定準則強調了領土控制與軍事力量的綜合重要性，而非單一指標。

城池數是首要判定標準，這反映了領土對遊戲戰略的基礎性影響。擁有更多城池的勢力通常擁有更廣闊的資源基礎與戰略縱深，因此在長期對抗中更具優勢。總兵力則作為次要判定標準，用於在城池數相同的情況下區分勢力的軍事實力。這種字典序比較確保了判定結果的確定性與公平性，避免了因單一指標導致的偏頗。例如，一個擁有 5 城但總兵力較低的勢力，將勝過一個擁有 4 城但總兵力極高的勢力，因為城池數的優先級更高。

這一判定準則也影響了玩家的終局策略。在遊戲後期，玩家需在擴張領土與保持軍事力量之間取得平衡。盲目擴張可能導致兵力分散，削弱單城防禦；而過度集中兵力則可能錯過擴張機會，導致城池數落後。因此，玩家需根據對局形勢，靈活調整戰略重心，以在城池數與總兵力之間取得最佳組合，最終贏得對局。這種策略深度使得遊戲不僅是數值的堆疊，更是戰略規劃與資源管理的綜合考驗。

## 本章重點

- 初始版圖由三勢力、九城與四十二位武將構成，鄰接關係定義了戰略空間與移動路徑。
- 金錢收入公式為 commerce // GOLD_INCOME_DIV，糧食收入公式為 agriculture // 4，均帶 U(0.8, 1.2) 隨機擾動。
- 部隊每回合消耗 troops // 10 糧食，斷糧時糧食歸零且兵力減少 10%（troops * 9 // 10）。
- 內政開發增益公式為 base * (50 + politics) // 100，武將政治力直接影響開發效率。
- 攻城最小兵力限制為 MIN_SIEGE_TROOPS = 500，戰鬥結算綜合考量兵力、武將能力與城防值。
- 勝負判定依 (城池數, 總兵力) 字典序裁定，城池數為首要標準，總兵力為次要標準。
- 經濟循環與軍事行動緊密相連，糧食與金錢的平衡是長期戰略成功的關鍵。

## 習題

1. 假設某城池商業值為 600，農業值為 400，駐軍 1000。若隨機擾動 rg 與 rf 均為 1.0，計算該城池本回合的金錢收入、糧食收入與維持成本，並判斷是否觸發斷糧機制。
2. 一位政治力為 80 的武將執行商業開發，基礎增量為 50。計算該次開發的實際增益值，並比較政治力為 40 的武將執行相同開發的增益差異。
3. 攻擊方動用 800 兵力攻城，出征武將武力 80、統御 70；防守城池駐軍 600，城防值 120，城內最優守將武力 75、統御 65。假設隨機擾動均為 1.0，計算攻防雙方的基礎實力，並判斷攻城是否成功。
4. 若遊戲結束時，faction_1 擁有 4 城、總兵力 5000；faction_2 擁有 3 城、總兵力 8000；faction_3 擁有 4 城、總兵力 4500。依字典序判定準則，哪一勢力獲勝？若 faction_1 與 faction_3 城池數相同，如何進一步比較？
5. 分析 MIN_SIEGE_TROOPS 與 SIEGE_MIN_GARRISON 的限制如何影響玩家的軍事調度策略。若移除這些限制，遊戲的戰略深度將如何變化？
