# 同盟(名義共主)機制設計草案

狀態:**只有草案,引擎尚未實作**。提出於 2026-11-03,由使用者的想法整理:歸屬會隨時間改變;袁紹這類共主與從屬者之間常是名義上的同盟,並無直接統治;可加一個「同盟」屬性,讓同盟國自動有一定友好值,並享有互助特權。

## 1. 資料層(已做)
`data/sanguo/candidates_officers.json` 的 `timeline_nim` / `timeline_agy` 以時間段表示歸屬,每段有 `relation`:
- `subordinate`:直屬部下(有直接統治)。
- `nominal_ally`:名義同盟或共主,沒有直接統治(例:反董卓聯軍盟主袁紹與各路諸侯)。
- `independent`:自立或割據。

另有 190、200、208、220 年四個時間點的陣營(`wei|shu|wu|others|none`)。兩個模型一致的年份放在 `faction_at`,不一致的放在 `needs_review`。這些都是模型答案,尚未對照史料。

## 2. 遊戲機制(建議,待你決定)
**同盟是兩個勢力之間的關係**,不是武將屬性。每對勢力有:
- `friendship`(0–100)。同盟成立時給一個基準值(建議 60),之後隨事件增減。
- `kind`:`nominal`(名義同盟,一方是盟主,彼此沒有統屬)或 `formal`(正式同盟)。

**互助特權**(由輕到重,可只開前幾項):
1. 同盟期間不得互相攻城(違反即視為背盟)。
2. 共享視野:看得到同盟城池的情報,補足戰爭迷霧。
3. 借道與援軍:集結兵力時可以調用同盟城池的部分閒置兵(沿用現有 `pool_factor`,但係數較低,例如 0.25)。
4. 糧食互助:每回合可向同盟轉讓一定量糧食(有上限),呼應行軍糧耗的設計。
5. 聯合攻城:相鄰的同盟城池對攻城方加一小段支援戰力。

**代價與限制**:
- 背盟(單方撕毀)使 `friendship` 對所有勢力下降,且短期內無法再結盟,避免投機。
- 友好值隨時間緩慢衰減,需要互助行動維持。
- 名義同盟的盟主沒有指揮權,只有「共同目標」才會觸發聯合攻城。

## 3. 引擎影響
- 新增狀態:`alliances`(勢力對、種類、友好值)。以規則集旗標控制(新增 `alliance=True`),**預設規則 `v2` 與現有評測不受影響**。
- 新增行動:`propose_alliance`、`break_alliance`(外交類,需在 `legal_actions` 與 `validation` 加規則)。
- 影響範圍:戰爭迷霧(視野共享)、兵力集結、出征驗證、網頁介面(盟友標示與外交面板)、LLM 提示詞,以及評測(需要新的對局結果比較)。

## 4. 建議的第一階段
只做最小可驗證的部分:同盟狀態 + 外交行動 + 「不得互攻」+「視野共享」。用 Nemotron 自我對弈比較有無同盟的勝負分佈,再決定要不要加兵力調用與糧食互助。
