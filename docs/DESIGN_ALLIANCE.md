# 同盟(名義共主)機制設計草案

狀態:**設計已定案方向,引擎尚未實作**。2026-11-03 提出想法,2026-11-04 使用者回覆了三個待決問題(見第 5 節)。

## 1. 資料層(已做)
`data/sanguo/candidates_officers.json` 的 `timeline_nim` / `timeline_agy` 以時間段表示歸屬,每段有 `relation`:
- `subordinate`:直屬部下(有直接統治)。
- `nominal_ally`:名義同盟或共主,沒有直接統治(例:反董卓聯軍盟主袁紹與各路諸侯)。
- `independent`:自立或割據。

另有 190、200、208、220 年四個時間點的陣營(`wei|shu|wu|others|none`)。兩個模型一致的年份放在 `faction_at`,不一致的放在 `needs_review`。這些都是模型答案,尚未對照史料。

## 2. 核心規則(使用者已決定)
**同盟是兩個勢力之間的關係**,不是武將屬性。範圍包含現有三勢力與未來的群雄勢力(袁紹、董卓等)。

每對勢力記錄:
- `friendship`(0–100):同盟成立給基準值(建議 60),隨事件增減,緩慢衰減。
- `kind`:`nominal`(名義同盟,有盟主但無統屬)或 `formal`(正式同盟)。
- `collateral`:雙方交付的抵押(可為空)。

### 2.1 締結
- 任何勢力都可以**主動提出**同盟:玩家、AI 君主皆可,不限事件觸發。
- **是否接受取決於友好值**,再由當下**主控 AI 判斷**(規則 AI 用門檻;LLM 勢力把友好值、局勢、對方實力放進提示詞後自行裁量)。
- 抵押是**可選的附加條件**,用來促成原本友好值不夠的同盟(例:友好值 40 的對象,願意交出人質或錢糧才答應)。

### 2.2 同盟期間的互動
- 可以**要求交換武將**,包含**親屬武將**(作為人質,也可作為借調)。
- 可以交付**金錢、糧食等資源**作為抵押。
- 互助特權(由輕到重,可分階段開):
  1. 不得互相攻城。
  2. 共享視野,補足戰爭迷霧。
  3. 援軍與借道:可調用同盟城池部分閒置兵(係數低於本方,例如 0.25)。
  4. 糧食互助(每回合有上限)。
  5. 聯合攻城:相鄰同盟城池對攻城方給小幅支援。

### 2.3 背盟的代價
- **背盟 = 單方撕毀,或攻擊盟友**。
- 後果一:背盟者與**所有同盟國**的友好值**大幅下降**(不只受害方)。
- 後果二:受害方**取走抵押物**(資源歸受害方;人質武將的處置待定,見第 5 節)。
- 友好值跌破門檻時,依規則自動解盟。

## 3. 引擎影響
- 新增狀態:`alliances`(勢力對、種類、友好值、抵押)。以規則集旗標控制(`alliance=True`),**預設規則 `v2` 與現有評測不受影響**。
- 新增行動:`propose_alliance`、`respond_alliance`(接受/拒絕/還價抵押)、`break_alliance`、`exchange_officer`、`pledge_resources`(外交類,需在 `legal_actions` 與 `validation` 加規則)。
- 影響範圍:戰爭迷霧(視野共享)、兵力集結、出征驗證、武將歸屬(借調與人質的所屬/忠誠)、網頁介面(盟友標示與外交面板)、LLM 提示詞、評測。
- 現有三勢力外交介面已有 diplomacy 場景圖可用。

## 4. 建議的分階段實作
1. **第一階段**:同盟狀態 + 提出/回應/解盟 + 友好值 + 不得互攻 + 視野共享 + 背盟懲罰(友好值)。用 Nemotron 自我對弈比較有無同盟的勝負分佈。
2. **第二階段**:抵押(資源)與背盟時沒收。
3. **第三階段**:武將交換與親屬人質;援軍、糧食互助、聯合攻城。
4. **第四階段**:群雄勢力(資料來自候選武將時間線,需先人工核對)。
