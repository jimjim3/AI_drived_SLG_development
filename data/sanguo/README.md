# 三國資料庫（累積中，測試階段**不被遊戲引擎使用**）

用途：為日後擴充城池、地圖、武將預先累積資料。目前引擎仍只用 `src/slg/engine/initial_state.py` 的 9 城 42 將。

| 檔案 | 內容 |
|---|---|
| `cities.json` | 城池／州郡治所：id、名稱、州、概略座標、地形標籤、戰略定位、相鄰城池 |
| `officers_<批次>.json` | 武將：id、名、字、陣營沿革、職能標籤、籍貫城、生卒（概略）、一句話定位、能力**估計** |
| `raw/` | agy／NIM 的原始輸出（除錯用） |
| `../../scripts/build_sanguo_dataset.py` | 產生器（呼叫 agy `ask`，無工具、僅文字） |
| `../../scripts/validate_sanguo_dataset.py` | 機械驗證：id 唯一、相鄰對稱、引用的城存在、欄位型別 |

## 可信度規則
- 所有能力值都是 `stats_estimate`，來源標註為模型記憶、**未經查證**（`verification: "unverified"`）。要作為遊戲數值前，必須對照光榮《三國志》系列公開資料並改成 `verified`。
- 座標為概略，用於相對位置，不可當地理資料。
- 與遊戲內現有 42 將重疊者保留相同 id（`in_game: true`），遊戲內數值仍以 `initial_state.py` 為準。

## 光榮《三國志11》參考值（`koei11_reference.json`，2026-10-28）
agy 網路研究（受限模式，只准搜尋）整理的 43 位武將統率／武力／智力／政治與一句社群評價，來源標註為日本攻略 wiki（atwiki.jp/sangokushi11）。**我無法獨立驗證**：該站對本機請求回 403，故狀態是 `agy_reported_unconfirmed`，不是 `verified`。agy 自述「評價聚焦於武將自帶特技與初始五維」，並提到呂蒙等人有劇本事件成長（吳下阿蒙 統 81→91）。

與遊戲內 41 位重疊武將比對（武力＋統率＋政治的絕對差總和，平均 23.8）：遊戲內數值普遍把「統率」壓得比光榮低（例：諸葛亮 75 vs 92、魯肅 60 vs 80），政治、武力則較接近；差最大的是賈詡、程昱、魯肅、諸葛亮。這顯示遊戲內數值是**自成一格的量尺**，不是光榮數值的複製，**不建議直接替換**。未重疊：徐晃（遊戲內沒有，可列入擴充候選）；凌統在遊戲內寫作「凌統」，資料為「淩統」（異體字）。

## NIM 交叉查核(`crosscheck_nim.json`,`scripts/crosscheck_sanguo.py`)
- Nemotron Ultra 對 186 位武將逐批查核,共 120 條旗標:home_city 80、字 17、陣營 14、生卒 7、解析失敗 2。
- **雜訊很大**:home_city 多半是把「遊戲內據點」當成「籍貫」;不少旗標自己寫「資料無誤」;陣營多半只是要把「漢室/東吳」這類非君主詞換掉。
- 生卒只有 2 條具體建議:關平卒 219(資料 220;史載建安二十四年十二月,換算西元為 220 年初,故資料不一定錯)、陸績卒 224(資料 219,有爭議)。
- **結論:沒有套用任何旗標,所有條目仍為 `unverified`。** 需要人或一手史料(《三國志》)才能升級。
